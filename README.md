# College Life Adventure Game

## About
This is a text-based game about college life.  
You make choices about course load, study focus, and life balance.  
Your GPA, study hours, stress level, and social points change based on what you pick.  
Different choices lead to different endings.

## Concepts Shown
- if / elif / else** – used in course load decision  
- Comparison operators (>=, <=, ==, !=) – check GPA and stats  
- Membership operators (in, not in) – validate study choices  
- Logical operators (and, or, not) – combine conditions  
- Identity operators (is, is not) – check input type  
- Nested if statements – final decision logic  
- Multiple endings – 3+ possible outcomes
